# Extended Scientific Programming in C Course

## From Wolfram Language to Fredholm Integral Equations


This document is an extended template for a semester-long scientific programming course.

### Learning Outcomes
- Scientific programming in C
- Numerical methods
- Git/GitHub workflows
- Linear algebra
- Integral equations
- Electromagnetic scattering
